# Mobile Geolocation Testing Guide (বাস্তব ফোনে জিপিএস টেস্টিং নির্দেশিকা)

**প্রজেক্ট:** Newtec Field Force Management (FFM)  
**ডকুমেন্ট:** `docs/ffm/02_mobile_geolocation_testing.md`  

---

## ১. কেন বাস্তব মোবাইলে HTTPS প্রয়োজন? (The HTTPS Requirement)

আধুনিক মোবাইল ব্রাউজারসমূহ (যেমন: Android Chrome, iOS Safari, Samsung Internet) ব্যবহারকারীর গোপনীয়তা ও নিরাপত্তা নিশ্চিত করার জন্য W3C Geolocation API (`navigator.geolocation`)-কে **Secure Context** (HTTPS অথবা `localhost`)-এর মধ্যে সীমাবদ্ধ রেখেছে।

- **সমস্যা:** আপনি যদি ডেভেলপমেন্ট মেশিনের লোকাল আইপি (যেমন: `http://192.168.1.15:8069/ff`) দিয়ে সরাসরি সাধারণ HTTP-তে মোবাইল থেকে প্রবেশ করেন, তবে ব্রাউজার স্বয়ংক্রিয়ভাবে জিপিএস অনুমতি ব্লক করবে এবং `[PERMISSION_DENIED] Only secure origins are allowed` ত্রুটি দেখাবে।
- **সমাধান:** সার্ভার অবকাঠামো (Infrastructure) পরিবর্তন না করেই নিচের সহজ ও নিরাপদ বিকল্পগুলোর যেকোনো একটি ব্যবহার করে বাস্তব মোবাইলে জিপিএস টেস্ট করা যায়।

---

## ২. অবকাঠামো পরিবর্তন না করে টেস্টিং অপশনসমূহ (Testing Options)

### অপশন ১: Cloudflare Tunnel (সর্বোত্তম ও সবচেয়ে সহজ - কোনো কনফিগারেশন ছাড়াই)
কোনো অ্যাকাউন্ট বা পোর্ট ফরোয়ার্ডিং ছাড়াই ক্লাউডফ্লেয়ারের মাধ্যমে তাৎক্ষণিক ফ্রি HTTPS টানেল তৈরি করা যায়:

1. `cloudflared` এক্সিকিউটেবল ডাউনলোড করুন অথবা উইন্ডোজ টার্মিনালে চালান:
   ```cmd
   winget install --id Cloudflare.cloudflared
   ```
2. ওডু সার্ভার পোর্ট ৮০৬৯-এর জন্য টানেল শুরু করুন:
   ```cmd
   cloudflared tunnel --url http://localhost:8069
   ```
3. টার্মিনালে একটি র্যান্ডম ফ্রি HTTPS লিংক প্রদর্শিত হবে (যেমন: `https://alpha-beta-xxxx.trycloudflare.com`)।
4. মোবাইলের ব্রাউজারে সেই লিংকটি খুলুন এবং `/ff` এ যান (যেমন: `https://alpha-beta-xxxx.trycloudflare.com/ff`)।

---

### অপশন ২: ngrok (জনপ্রিয় অল্টারনেটিভ)
1. ngrok টার্মিনালে কমান্ড দিন:
   ```cmd
   ngrok http 8069
   ```
2. প্রদর্শিত HTTPS ফরওয়ার্ডিং ইউআরএল (যেমন: `https://xxxx.ngrok-free.app/ff`) দিয়ে মোবাইলে প্রবেশ করুন।

---

### অপশন ৩: Chrome USB Remote Debugging (ইন্টারনেট বা টানেল ছাড়া)
যদি কেবল ইউএসবি কেবলের মাধ্যমে অফলাইনে টেস্ট করতে চান:
1. অ্যান্ড্রয়েড ফোনে **Developer Options -> USB Debugging** চালু করুন এবং পিসির সাথে ক্যাবল যুক্ত করুন।
2. পিসির গুগল ক্রোমে টাইপ করুন: `chrome://inspect/#devices`
3. **Port forwarding** বাটনে ক্লিক করে `8069` পোর্টকে `localhost:8069`-এ ম্যাপ করুন।
4. এবার ফোনে ক্রোম ব্রাউজার খুলে সরাসরি টাইপ করুন: `http://localhost:8069/ff`
5. যেহেতু ফোন এটি `localhost` হিসেবে দেখবে, ক্রোম এটিকে **Secure Context** হিসেবে গণ্য করবে এবং জিপিএস সঠিকভাবে কাজ করবে।

## ৩. বাস্তব ফোনে ফিল্ড টেস্টিং চেকলিস্ট (Field Testing Checklist)

1. মোবাইলের সেটিংস থেকে **Location (GPS)** চালু আছে কিনা নিশ্চিত করুন (High Accuracy মোড)।
2. ব্রাউজারে `/ff` পেজে প্রবেশ করে ডেমো ফিল্ড পারসন হিসেবে লগইন করুন:
   - **ব্যবহারকারীর নাম:** `ffm_fp_demo`
   - **পাসওয়ার্ড:** `Demo12345!`
3. ড্যাশবোর্ড থেকে **দৈনিক হাজিরা (Daily Attendance)** টাইলে ক্লিক করুন।
4. **"📡 আমার অবস্থান শনাক্ত করুন (Capture GPS)"** বাটনে ট্যাপ করুন।
5. ব্রাউজার লোকেশন পারমিশন চাইলে **"Allow"** দিন।
6. স্ক্রিনে কয়েক সেকেন্ডের মধ্যে অক্ষাংশ (Latitude), দ্রাঘিমাংশ (Longitude) এবং নির্ভুলতা ব্যাসার্ধ (Accuracy in meters) প্রদর্শিত হবে।
7. ভ্রমণের মাধ্যম (যেমন: মোটরসাইকেল/বাস) নির্বাচন করে **"হাজিরা নিশ্চিত করুন (Submit Attendance)"** বাটনে ট্যাপ করুন।
8. সফলভাবে সাবমিট হলে স্ক্রিনে সবুজ টিকচিহ্নসহ উপস্থিতির রসিদ এবং **"গুগল ম্যাপে অবস্থান দেখুন"** বাটন প্রদর্শিত হবে।
